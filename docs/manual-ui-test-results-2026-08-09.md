## 人性化完善

- 用户是否知道发生了什么：扫描、预览、导入和撤销均给出数量与逐项状态；导入和撤销前有明确二次确认。
- 用户是否知道下一步做什么：异常记录现在可通过首页“刷新”直接复核旧目录，不必猜测设置中最后记住的是哪个目录。
- 用户是否知道文件是否安全：只读扫描明确列出不会执行的动作；导入明确说明复制、大小与 SHA-256 校验、同名不覆盖；撤销后文件数量与总字节回到基线。
- 非阻塞建议：将首页“删除”在全选缺失记录时动态改为“清理记录”，减少用户对“是否会删真实文件”的担忧。
